## Verdict

Productni smjer je **native `qnc-app` + `qnc-host`**. Milestone 1 (Project-first shell) je **već premašen** u kodu: Project / Ingest / Story egui ekrani postoje; `cargo check -p qnc-app` prolazi.

Kritični jazovi:

1. Playback još **nije** broadcast-grade (host JPEG, `FRAME_INTERVAL` 200 ms ≈ 5 fps).
2. `qnc-app/src/broadcast/` (~5.5k LOC) je scaffold — **nije** spojen na Story UI.
3. Web + WASM tragovi još žive iako ih migration plan **odbacuje**.
4. Folder **nije git repo** — nema history/PR sidra.
5. `test.ps1` zove `scripts/db-first-guard.ps1` koji **ne postoji**.
